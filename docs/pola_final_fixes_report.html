Details

1. Elimu ya Kisheria Hub – Language Translation Resolved

What we did: The English "Read More" text has been removed from the Elimu ya Kisheria cards and the Swahili translation "Soma Zaidi" is in place throughout the Swahili version of the app.

2. Phone Number Field – Validation and Visual Feedback Resolved

What we did: The phone number field now gives instant feedback while typing: a green border with a check mark when the number is valid and complete, and a red border with a warning icon when it is incorrect or incomplete. This applies to Sign-up, Subscription and Voucher purchase.

3. Professional Specialization – Sign-Up Process Resolved

4. Advocate Hub – Role-Based Access Resolved

What we did: Access to the Advocate Hub is now limited to verified Advocates (and administrators), both in the app and on the server. Lawyers, Paralegals, Law Firms and other roles can no longer view or post in this section.

5. Professional Account Verification – Requirements Mismatch Admin configuration

What we did: The app now reads the required verification documents directly from the Admin Panel, so there is a single source of truth: whatever is configured in the Admin Panel (documents and whether each is mandatory) is exactly what the app asks for. New document types added by the administrator (for example a Practising Certificate) can now also be uploaded.

Remaining step: The administrator sets the final document list for Lawyers and Paralegals in the Admin Panel.

6. Student Hub – Access and Content Configuration Resolved

A. Access: The "Failed to load content" error was caused by an access rule that did not recognise the Student role. This is fixed – Students and Lecturers can now open the Student Hub. Content posted by students is also now correctly labelled as student content.

B. Monetized content: The price options have been removed. Every downloadable document now has a fixed download price of TZS 1,500, shown on each document, and the server enforces this price. Reading content remains free for users with an active subscription.

7. Legal Templates – Incomplete Content and Swahili Versions Next phase

The app already supports English and Swahili versions of each template (Employment Contract / Mkataba wa Ajira, Notice of Termination / Notisi ya Kusitisha Ajira, Resignation Letter / Barua ya Kujiuzulu). The remaining templates – Car or Motorbike Rental, Motor Vehicle or Motorcycle Sale, House Rental, Minutes of Family Meeting on Probate, and Will – are scheduled for the next phase.

8. Lecturer Role – Sign-Up Options Resolved

What we did: Lecturer (Mhadhiri) is now available as a separate role during registration, with access to the Students and Lecturers Hub.

9. Professional Verification – Document Upload Failure Resolved

Cause: This was a system issue, not the network. The app was not sending a piece of information (the document title) that the server required, so every upload was rejected.

What we did: Fixed on both the server and the app. If an upload ever fails in future, the app now shows the actual reason (for example "document already submitted" or "check your connection") instead of a general error.

10. Automatic Sign-Out – Session Management Resolved

What we did: Users previously had to sign in again every 12 hours. Users now stay signed in as long as they use the app at least once every 90 days, similar to common social media apps. Professionals will no longer appear offline because of an expired session. The existing one-device security rule remains: signing in on another device still signs out the previous device.

Availability: These fixes will be live after the next server update and the next app release on Google Play / App Store. Users should update to the latest app version to receive all improvements.
